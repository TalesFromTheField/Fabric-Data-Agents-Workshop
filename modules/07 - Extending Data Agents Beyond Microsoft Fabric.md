<p style="border-bottom: 1px solid lightgrey;"></p>

<img style="float: left; margin: 0px 15px 15px 0px;" src="../graphics/textbubble.png"> <h2>Extending Data Agents Beyond Microsoft Fabric</h2>

You've built a Fabric Data Agent. It answers questions, it grounds on your data, and it does it all from the comfort of the Fabric portal. That's lovely - right up until someone in Finance asks, "Great, but can I just ask it in Teams?"

This module is about getting your Data Agent out of the building. A Fabric Data Agent isn't a destination, it's an endpoint. Once you understand that, you can surface the same governed, grounded agent in Microsoft Foundry, Copilot Studio and Teams, your own Python applications, and Microsoft 365 Copilot - without rebuilding the semantics, the grounding, or the security model each time.

In each section you'll get more references, which you should follow up on to learn more. Also watch for links within the text - click on each one to explore that topic.
